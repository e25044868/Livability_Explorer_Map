# 0002：公共連線與安全據點資料來源

## 決策

平台新增三項全國官方資料類別：公共免費 Wi-Fi、消防／救援據點、警察機關／派出所。
各來源均經過受限 HTTPS 下載、原始快照、欄位驗證、座標驗證與品質閘門後，才會發布至 PostGIS。

## 資料與座標處理

- iTaiwan Wi-Fi 使用資料集 5962 原始 WGS84 經緯度。
- 消防／救援據點使用資料集 5969。雖然欄名含 `TWD97TM121`，實際公開值為可驗證的經度、緯度；發布前仍以臺灣座標範圍驗證。
- 警察機關使用資料集 5958，原始 `POINT_X`、`POINT_Y` 是 TWD97 TM2（EPSG:3826），以 `pyproj` 轉為 WGS84 後標記為 `converted_coordinate`。

## 延後項目

- 公共自行車依 TDX 供應，需由管理者在環境變數提供 TDX client credentials；不會把金鑰放入來源設定或前端。
- 垃圾清運資料由各地方政府分別供應，沒有可審核的單一全國來源。後續以指定城市為單位新增來源設定、欄位正規化與品質測試，不以不完整資料宣稱全國覆蓋。

## 更新風險

警察資料下載檔是 TGOS 版本化資源。若官方更換檔名或路徑，下載器會安全失敗並保留已發布資料，需更新 `data_sources/police_taiwan.yaml` 的公開下載 URL 後重跑。
